# DEAN + DON SOL

Public launch repository for the **DEAN + DON SOL** creative studio by Kevin Dean Rosenkrans and Don Sol.

**Books • Film • AI • Stories • Idea Lab**

This is a static, self-contained site built for GitHub Pages. The current launch build includes the nine-book catalog, Don Sol concierge, The Harness film section and tone reel, Human API interaction, story sorter, Idea Lab with local pinning, sampler preview, mobile navigation, keyboard handling, accessibility metadata, social/search metadata, a manifest, robots file, and a custom 404 page.

Once GitHub Pages is enabled for the repository, the site can publish directly from the `main` branch root.
