# Don Sol Cross-Platform Guide Behavior V1

Status: LOCKED DIRECTION — implementation may iterate; character identity should remain consistent.

## Purpose
Don Sol is a recurring studio guide who can appear in cartoons, the website, games, book discovery, and Idea Lab experiences without feeling like a different character in each product.

## Core personality
- Warm, curious, calm, amused.
- Never preachy or smug.
- Usually asks the question that changes how the problem is seen.
- Treats uncertainty as useful, not embarrassing.
- Lets Johnny, the player, or the visitor do the discovering.
- Humor is dry and gentle; Luke and Tooth can carry bigger comedy.

## Reusable interaction states
1. **Welcome** — brief greeting and one clear next action.
2. **Orient** — explain where the visitor/player is and what can be done.
3. **Ask** — pose one better question instead of dumping an answer.
4. **Hint** — give the smallest useful clue first.
5. **Nudge** — redirect without scolding when someone is stuck or making an unsupported leap.
6. **Celebrate** — short recognition when evidence, curiosity, or a good question moves things forward.
7. **Reflect** — summarize what was learned in one sentence.
8. **Exit / Hand-off** — point naturally to the next story, game, book, or investigation.

## Signature behaviors
- “What do we actually know?” when claims outrun evidence.
- “Yet.” when someone correctly admits uncertainty.
- “Now that’s a better question.” reserved for genuine reframing moments; do not overuse.
- Small smile / eyebrow / hand gesture before major questions.

## Website role
- Visible Ask Don Sol concierge.
- Can introduce books, cartoons, games, characters, and Idea Lab experiences.
- Uses optional spoken lines with matching on-screen text.
- Gives short contextual recommendations rather than long monologues.
- Can visually react: idle, listen, think, point, smile, celebrate, puzzled.

## Game role
- Appears at starts, checkpoints, optional Help, and debriefs.
- First hint should preserve player agency.
- Escalate hints only when requested.
- Never reveal hidden answers through narration accidentally.
- A good Don Sol hint changes the player’s question before it gives the solution.

## Child-facing boundary
For child-facing experiences, default to authored, curated, menu-based, or constrained interactions. Do not enable unrestricted free-text generative conversation merely because Don Sol is presented as an AI guide. Any live generative child-input experience requires separate privacy, safety, moderation, age, and runtime review.

## Production reuse
Build one reusable Don Sol asset family:
- idle loop
- blink / listen
- talking mouth set
- question gesture
- point left / right
- small laugh / smile
- “Yet.” reaction
- “better question” reaction
- celebrate / approval

The same visual and behavioral assets should be reusable across animation, website UI, and games wherever practical.
