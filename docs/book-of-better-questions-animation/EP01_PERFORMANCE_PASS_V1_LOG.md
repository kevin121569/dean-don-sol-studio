# THE BOOK OF BETTER QUESTIONS — EPISODE 01 PERFORMANCE PASS V1

Status: **LOCAL PERFORMANCE PASS COMPLETE**

## Purpose
Move beyond simple pan/zoom motion by testing audio-driven character performance while preserving the approved character designs.

## Scope
This pass applies only to the opening hallway exchange:
- Johnny: "There's a room back there."
- Tooth: "You walked past a wall."
- Johnny: "Exactly."
- Tooth: "That is not the same sentence."
- Luke: "Architecture... of destiny."

## New performance layer
- dialogue waveform drives subtle mouth-region deformation,
- speaking characters receive small voice-synced head/breath motion,
- subtitle bar remains stable,
- existing camera motion is preserved,
- no redesigns or new character geometry were introduced.

## Production lesson
The next quality increase should come from performance, not from replacing the cast.

Priority order for future passes:
1. mouth timing,
2. eye/head reaction timing,
3. gesture timing,
4. secondary motion (Luke ears/tail, Tooth arm/screen expressions),
5. cleaner voice performances,
6. only then additional visual complexity.

## Cost discipline
The connected external video-generation workspace had zero available credits during this pass. No paid generation was attempted. The test was produced locally from already-approved assets and existing audio.

## Acceptance rule
This pass is successful if the characters feel incrementally more alive without changing who they are or forcing a more expensive animation style.

This is a bridge toward full rigged/AI-assisted character animation, not a claim of final lip-sync.
