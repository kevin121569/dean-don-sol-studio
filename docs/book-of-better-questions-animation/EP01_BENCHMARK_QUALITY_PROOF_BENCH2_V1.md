# Episode 01 — Benchmark Quality Proof BENCH2 V1

Status: PASS — benchmark reference only

## Purpose

BENCH2 applies the post-BQ11 benchmark workflow to Luke + Tooth.

Tooth is the cleanliness control. Luke is the character being pushed toward the same restrained, believable limited-animation standard.

This is **not** an episode cut.

## Canonical dialogue

- Luke: “Hidden chamber. Secret passage. Architecture… of destiny.”
- Tooth: “Please stop helping.”

## Benchmark goals

- preserve Luke’s face/anatomy without fake muzzle overlays or clipping
- replace constant puppet wiggle with anticipation → emphasis → settle
- use subtle jaw/head motion rather than crude mouth replacement
- keep Tooth comparatively still so the deadpan contrast remains funny
- use clean dry dialogue with no inherited episode mix
- reject any version that looks more artificial even if it technically moves more

## QA history

An intermediate full-body Luke treatment was rejected internally because the mouth treatment looked artificial.

The accepted BENCH2 returned to the clean close-up art and retained only the timing improvements.

## Accepted result

- duration: 7.87 seconds
- H.264/AAC
- full decode: PASS / zero errors
- Luke: restrained head/camera acting + subtle jaw motion + clear settle
- Tooth: clean screen-face speech + minimal body/camera movement
- clean fresh caption layer
- clean dry dialogue only

## Production meaning

BENCH2 reinforces the benchmark rule:

**More movement is not automatically better.**

A character passes only when motion improves the illusion of thought/performance without damaging anatomy, silhouette, or visual cleanliness.
