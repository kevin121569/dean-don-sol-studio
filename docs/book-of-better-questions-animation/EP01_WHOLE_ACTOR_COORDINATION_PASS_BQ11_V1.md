# Episode 01 — Whole-Actor Coordination Pass (BQ11) V1

Status: PASS — review cut produced

## Purpose

BQ11 addresses the remaining puppet-like separation between facial acting, head motion, shoulders, and gestures.

The governing motion rule is:

**eyes/head intention → body prepares → gesture/emphasis → settle**

The goal is not more movement. The goal is coordinated movement that reads as one actor making one thought.
