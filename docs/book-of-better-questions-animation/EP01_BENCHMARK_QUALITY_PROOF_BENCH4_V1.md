# Episode 01 — Benchmark Quality Proof BENCH4 V1

Status: PASS — benchmark reference only

## Purpose

BENCH4 tests whether the established character-animation language survives a teaching-heavy ensemble scene in which the environment itself carries part of the lesson.

This is not a full episode cut.

## Canonical teaching beat

Don Sol asks:

**“What do we actually know?”**

Johnny answers:

**“The hallway. The blank wall. The geometry feels weird.”**

The three observation cards then settle under **WHAT WE SAW**.

## Benchmark goals

- multiple characters remain visually stable in one teaching scene
- character attention shifts toward the Fact Wall without constant motion
- Tooth receives a restrained screen-eye reaction
- the Fact Wall behaves like an active teaching element
- all three observation cards land only under WHAT WE SAW
- WHAT WE THINK and WHAT WE DON’T KNOW remain untouched
- clean dry dialogue with no inherited episode audio
- no clipping, broken anatomy, or inherited subtitles

## Result

- duration: ~7.77 seconds
- 1280×720 H.264/AAC
- full decode: PASS / zero errors
- HALLWAY, BLANK WALL, and GEOMETRY FEELS WEIRD are legible and visibly grouped beneath WHAT WE SAW
- teaching logic remains correct
- ensemble motion remains restrained

## Production meaning

BENCH4 proves that character acting, environment animation, and instructional structure can coexist in one shot without requiring full-frame character animation.

## Next step

If user review confirms the improvement is visually obvious, the next benchmark should combine:
- a short walk/entrance
- dialogue acting
- silent reaction
- environment response

Only after that should a longer sequence from Episode 1 be rebuilt using proven benchmark methods.
