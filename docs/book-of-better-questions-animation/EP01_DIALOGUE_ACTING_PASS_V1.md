# Episode 01 Dialogue Acting Pass V1

Status: PASS — FIRST CHARACTER-SPECIFIC VISEME DIALOGUE ACTING PROOF

## Purpose
Move beyond generic open/close mouth motion and prove reusable character-specific speech performance inside real Episode 01 dialogue shots.

## Characters tested
- Johnny
- Don Sol

## Viseme set
- REST
- MBP (closed-lip consonants)
- E
- AI
- O
- UW
- FV
- TH
- L
- N

## Episode dialogue used
Johnny: “There’s a hidden room behind that wall.”

Don Sol: “What do we actually know?”

## Acting layers present
- distinct mouth shapes selected across the spoken phrase
- blink beats
- small head/camera performance beat
- return to neutral/rest after speech
- clean caption replacement so inherited source captions cannot contradict new audio

## QA catches before PASS
1. Don Sol’s source frame contained the inherited caption “What are we proving today?” while the new audio said “What do we actually know?” The inherited caption was stripped and replaced.
2. The first blink implementation produced a translucent/ghost-eye intermediate. Blink treatment was changed to an opaque fast eyelid closure.
3. Final combined file was fully decoded end-to-end with zero errors.

## Production rule
Speech animation must be based on a reusable viseme vocabulary, not merely audio amplitude. Character acting may layer blink, eye, head, hand and camera beats around the mouth rig, but the face must not be globally warped.

## Next application
Apply the same mouth-pack logic across remaining Episode 01 dialogue shots, prioritizing Don Sol’s mentor beats and Johnny’s question/reaction beats, then Tooth and Luke character-specific facial systems.
