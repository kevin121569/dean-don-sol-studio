# Don Sol Mentor Entrance Module V1

Status: PASS — reusable mentor-motion module.

## Purpose
Create one repeatable Don Sol motion pattern that works in the cartoon and can later be adapted to website/game guidance.

## Beat sequence
1. Enter the Idea Lab.
2. Settle before speaking.
3. Ask: **“What do we actually know?”**
4. Redirect attention toward the Fact Wall / evidence.

## Production rules
- Use locked Don Sol visual identity.
- Prefer clean keyframes and controlled regional motion.
- No whole-face warp shortcuts.
- Entrance motion should read as calm mentor presence, not comic rushing.
- Hand emphasis accompanies the question beat.
- The evidence redirect should move viewer attention from mentor to the problem space.

## Cross-platform reuse
The same behavior pattern can map to interactive use:
- website: Don appears, greets, asks a clarifying question, points to a relevant section;
- game: Don appears after a stall, asks what is known, then highlights evidence rather than giving the answer;
- cartoon: Don enters confusion and turns the room toward disciplined inquiry.

## Learning role
Don is not the answer machine. His recurring function is to convert confusion into a better question.

Canonical lines include:
- “What do we actually know?”
- “What are we assuming?”
- “What don’t we know yet?”
- “Now that’s a better question.”
