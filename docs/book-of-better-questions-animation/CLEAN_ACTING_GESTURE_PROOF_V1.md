# Clean Acting + Gesture Proof V1

Status: PASS — use this as the safer low-cost acting recipe going forward.

## Why this proof exists

The earlier region-warp performance experiments occasionally smeared facial features on in-between frames. This proof replaces that unstable shortcut with a clean-keyframe approach that keeps the locked character art intact while still adding life.

## What is demonstrated

- Don Sol: natural blinks, subtle dialogue-driven mouth motion, open-hand emphasis on the question beat, gentle camera push.
- Johnny: natural blinks, subtle dialogue-driven mouth motion, tiny conviction/head beat, gentle camera push.
- Tooth: skeptical screen-eye squint/blink, subtle screen-mouth motion, small card/hand bob, gentle camera push.
- Original dialogue audio and subtitles preserved.
- No character redesign.
- No full-face warp.

## Production rule

Prefer clean keyframes plus controlled local animation (eyes, mouth/jaw region, hands/props, head beats, camera) over whole-face deformation. If a motion shortcut visibly distorts identity, discard the shortcut rather than normalizing the defect.

## Result

The clip demonstrates the first three dialogue shots of the Don/Fact Wall sequence using the clean acting recipe. This should become the template for the rest of Episode 1 and later episodes until higher-budget rigging is justified.

Acceptance: PASS.
