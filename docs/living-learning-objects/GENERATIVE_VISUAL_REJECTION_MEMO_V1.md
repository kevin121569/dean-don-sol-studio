# LIVING LEARNING OBJECTS — GENERATIVE VISUAL REJECTION MEMO v1

Status: **PRODUCTION SAFETY / CANON PROTECTION**  
Tracked by GitHub Issue #23 / PR #24.

## Decision

The recent multi-character AI-generated concept boards are **REJECTED AS PRODUCTION REFERENCES**.

They may remain useful only as broad mood/lighting inspiration. They do not define character appearance, proportions, silhouettes, materials, or canon.

## Why they fail

The boards introduced material character drift:

- Percy was reinterpreted as a yellow anthropomorphic mascot instead of the locked paired-parenthesis form.
- Clipper was reinterpreted as a human grandfather instead of the paper-clip character.
- Hue was reinterpreted as a blue question-mark mascot instead of a real highlighter.
- Mobi was reinterpreted as a robot instead of a visibly mobile phone AI interface.
- Character scale and anatomy were invented independently of the production-locked website forms.

These are not cosmetic deviations. They break the series' core rule: **characterization may enrich the object; it may not disguise the object.**

## Production rule

No generated visual may become a reference merely because it is attractive.

Reference priority is:

1. production-locked site geometry/material identity,
2. Character Pack v2 proof forms,
3. Episode 001 story/visual locks,
4. deterministic reference sheets/proof frames,
5. generated style exploration only after 1–4 are preserved.

If a generated image conflicts with any higher-priority source, the generated image loses.

## Correct next method

Before further generative art or animation:

1. build deterministic character reference sheets from the exact locked CSS/SVG forms,
2. build deterministic environment/blocking diagrams,
3. build deterministic Percy hero proof frames using the exact paired-parenthesis silhouette,
4. approve those geometry proofs,
5. only then use image-to-image / controlled reference workflows to add cinematic texture and dimensionality.

## Hard character locks

### Percy
- one character represented by two coordinated parentheses,
- canonical curve geometry derives from the locked Percy SVG,
- no mascot body replacing the punctuation form,
- no growth, stretching, braces/brackets, or duplicate twins.

### Clipper
- remains visibly a paper clip,
- permanent slight bend,
- may be expressive but may not become a human grandfather.

### Hue
- remains visibly a real highlighter with marker body/cap/chisel-tip logic,
- may be expressive but may not become a question-mark creature.

### Mobi
- remains visibly a mobile phone,
- may animate screen/pose within that form,
- may not become a robot body or floating AI mascot.

## Verdict

**GENERATED BOARD SET: HOLD / NON-CANON.**

Do not train, storyboard, animate, or build downstream reference packs from those boards.

Next gate: deterministic canon-safe visual proofs.
