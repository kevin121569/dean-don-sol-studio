# PERCY MOTION PROOF V1 — NOTES

Status: **LOCAL ANIMATIC PROOF / NOT FINAL ANIMATION**

Tracked by Issue #23 / PR #24.

## Purpose

This proof exists to answer one question before any larger production spend:

> Can the approved Percy design carry the key story beat with very little animation?

The proof tests the four-beat chain:

1. Percy realizes what she is for.
2. Percy opens into her parentheses working form.
3. The parentheses move into position around the related cards.
4. Percy says: **“I’ve got you.”**

## Runtime

Approx. 13.7 seconds.

## Production method

The proof deliberately uses the cheapest viable motion language:

- approved storyboard art,
- held drawings,
- subtle camera push / zoom,
- simple cuts,
- placeholder synthesized voice,
- no full character rig,
- no frame-by-frame body animation,
- no expensive transformation effect,
- no final score or sound design.

## What this proves

A PASS means the emotional/story beat can work with voice, timing, composition, and very limited motion.

It does **not** yet prove:

- final voice casting,
- final lip sync,
- production animation quality,
- finished sound design,
- final card motion,
- final website implementation.

## Canon locks preserved

- Percy is an ordinary friendly illustrated girl in normal mode.
- Her head/face opens into the parentheses working form.
- She remains one character.
- No giant growth, forcefield, remote grabbing, or arbitrary magic.
- The cards are already a related set before Percy brackets them.
- “I’ve got you” remains the emotional payoff.
- Clipper remains the approved warm Grandpa paper-clip design.

## Website reuse

The same production assets should later support website-guide use:

- Percy normal idle,
- Percy curious / thinking / concerned / determined expressions,
- Percy working form,
- Percy “I’ve got you” pose,
- Clipper warm idle / speaking reaction.
