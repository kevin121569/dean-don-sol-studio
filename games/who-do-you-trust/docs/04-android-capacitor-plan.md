# 4 · Android / Capacitor Packaging Plan

**Principle:** The web game is the product. The Android app is a thin native shell around the *same files*. No forked UI and no native-only features in Episode 01.

## Repository layout

Create a **separate repo**, `idea-lab-games-android`, rather than putting the native project inside the site repo:

```
idea-lab-games-android/
├── package.json            @capacitor/core, /cli, /android, /preferences, /haptics, /app, /status-bar, /splash-screen
├── capacitor.config.json   appId com.theidealabstudio.whodoyoutrust · appName "Who Do You Trust?" · webDir "www"
├── scripts/sync-web.mjs    copy dean-don-sol-studio/games/who-do-you-trust → www/ (excluding docs/, tests/, sw.js, manifest)
├── resources/              icon-only.png 1024², splash 2732² → @capacitor/assets generates every density
├── android/                generated by `npx cap add android`, committed (Capacitor's recommendation)
└── www/                    build output, git-ignored
```

The site repo stays a pure static site, and the Android repo pins a **specific commit** of the game, so every Play release is reproducible.

## Build pipeline

1. `npm run sync-web` copies the game at a tagged commit.
2. `npx cap sync android` copies www and updates plugins.
3. Android Studio / `./gradlew bundleRelease` produces a signed **AAB** (Play requires AAB, not APK).
4. Upload to Play Console, Internal testing track.

## Native integration (all inside `src/platform/`)

| Concern | Web | Android |
|---|---|---|
| Saves | localStorage | `@capacitor/preferences`, saved on `pause` too |
| Back button | browser back = UI back | `App.addListener('backButton')` → close panel → previous screen → confirm exit |
| Offline | service worker | files are bundled; SW not registered |
| Haptics | none | light tick on paste, medium on decision |
| Safe areas | `env(safe-area-inset-*)` | same, plus `StatusBar.setOverlaysWebView` |
| Orientation | responsive | portrait on phones; both orientations on tablets |
| Network | none needed | none requested; **no INTERNET permission** if nothing needs it |

## Google Play requirements checklist

> Verify each item in Play Console at submission time. Policies change.

- [ ] **Developer account:** personal or organization. New *personal* accounts must run a **closed test with at least 12 opted-in testers for 14 continuous days** before they can apply for production access.
- [ ] **Target API level:** meet Play's current minimum target SDK. Set it in `android/variables.gradle`.
- [ ] **App signing:** enroll in Play App Signing. Keep the upload keystore and its passwords **out of git** and backed up in two places.
- [ ] **Privacy policy URL:** required even with no data collection. Host at `theidealabstudio.com/privacy/`.
- [ ] **Data safety form:** "No data collected / no data shared" is accurate if saves stay on-device and there is no analytics or network access. That's the main payoff of the offline architecture.
- [ ] **Content rating:** complete the IARC questionnaire (no violence, no purchases, mild peril).
- [ ] **Target audience:** **decision needed.** If under-13s are in the target audience, the Families policy applies: stricter ads/SDK rules and teacher-approved review. Recommendation: 13+ for Episode 01, and revisit for a Book of Better Questions spin-off.
- [ ] **Store listing:** title, short description (80 chars), full description, 512² icon, 1024×500 feature graphic, and at least 2 phone screenshots plus 7"/10" tablet screenshots.
- [ ] **Monetization:** none in v1. Paid apps need the same payments profile already set up for Play Books.

## Versioning

`version.json` in the game is the single source of truth. `versionName` = game version (`0.1.0`). `versionCode` = a monotonically increasing integer that the sync script derives from it, e.g. `0.1.0 → 100`.

## Device test matrix before each Play release

At least one low-end Android phone (≤ 3 GB RAM), one current phone, and one tablet. Test portrait and landscape, TalkBack on, font scale 200%, kill-and-restore from recents, and airplane mode for the whole session.
