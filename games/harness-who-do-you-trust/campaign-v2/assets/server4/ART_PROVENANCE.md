# Server 4 original evidence art

These five evidence-card illustrations were generated with the built-in OpenAI
image-generation tool on 2026-10-27, then cropped to a consistent 720×432 JPEG
at quality 84 for the offline campaign package.

Shared production prompt:

> Landscape evidence-card illustration for an investigation game for ages
> 10–14; polished cinematic 3D storybook style; deep navy and electric cyan
> with warm amber highlights and restrained red warnings; one clear focal
> subject; the same secure Server 4 data-center environment; no logos,
> watermark, magnifying-glass badge, or harbor imagery.

Asset-specific prompts:

- `monitor-alert.jpg` — a rugged monitor showing an abstract warning and
  outbound data pulses, communicating an allegation rather than proof.
- `controller-log.jpg` — a physical isolation console, changing port lights,
  and two nearby clocks, emphasizing an official recorded sequence.
- `technician-statement.jpg` — a capable technician with a tablet and an
  uncertain open-hand gesture beside Server 4.
- `containment-protocol.jpg` — an emergency binder, guarded shutdown control,
  and fragile memory module showing the containment-versus-evidence tradeoff.
- `clock-sync.jpg` — paired facility clocks with a small visible offset, a calm
  archive path, and a red isolation barrier.

The generated art is an allowlisted presentation delta. The approved Level 1
story, rules, evidence text, and frozen monolith remain unchanged.
