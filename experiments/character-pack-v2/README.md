## Design constraints

- Objects must remain visibly the physical/typographical forms they already are.
- Material coherence, not mascot coherence.
- Meaningful text must be deterministic.
- Essential interactions cannot be hover-only.
- Reduced-motion behavior must preserve function.
- Interactive controls must be semantic and keyboard accessible.
- Decorative objects must remain outside the accessibility focus order.
- No glow, particles, fog, magic, forcefields, faces, limbs, or costume-like mascot features.
- Commerce and reading clarity outrank character animation.

## Gate before integration

No v2 production integration until the package has passed isolated identity/function review, reduced motion, desktop placement, 375×812 mobile placement, accessibility semantics, and runtime/telemetry review.
